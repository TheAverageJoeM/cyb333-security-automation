# CYB333 Security Automation

This repository contains coursework, notes, screenshots, and project files for CYB333 Security Automation.

## Repository Structure

- `week1-environment-setup` - Files and screenshots for the Week 1 environment setup assignment.
- `final-project` - Project files for the Windows Event Log Threat Hunting Toolkit.
- `screenshots` - Supporting screenshots for assignments and documentation.
- `notes` - Course notes and planning documents.

## Final Project

The final project for this course is a PowerShell-based Windows Event Log Threat Hunting Toolkit. The goal of the tool is to automate the review of Windows security logs and identify suspicious activity such as failed logins, PowerShell activity, new account creation, and service creation events.
