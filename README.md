# CYB333 Security Automation

This repository contains coursework, assignments, notes, screenshots, and project deliverables completed for CYB333 Security Automation at National University.

The purpose of this repository is to document hands-on experience with security automation concepts including Python scripting, PowerShell automation, network programming, event log analysis, and automated security reporting.

## Repository Structure

### Week1-Environment-Setup

Contains files and screenshots related to the initial development environment configuration, including Python, Jupyter Notebook, GitHub, and supporting tools used throughout the course.

### Midterm

Contains the CYB333 Midterm project files, including:

* Socket client and server applications
* Port scanner implementation
* Project screenshots
* Reflection documentation

### Final-Project

Contains the Windows Event Log Threat Hunting Toolkit project.

The project demonstrates security automation by using Python and PowerShell to collect Windows Security Event Log data, identify security-relevant events, and generate automated reports.

Project contents include:

* Python source code
* Generated reports
* Project screenshots
* Project documentation

### Screenshots

Contains screenshots supporting course assignments and lab activities.

### Notes

Contains planning documents, notes, and supporting materials used during the course.

## Final Project Summary

The Windows Event Log Threat Hunting Toolkit automates the review of Windows Security Event Logs by searching for security-related Event IDs and generating reports in CSV and JSON format. The project demonstrates how automation can reduce repetitive security monitoring tasks and improve efficiency during log analysis.
